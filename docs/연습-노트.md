# 연습 노트 (PR 실습용)

이 문서는 **직접 PR 한 바퀴를 연습**하기 위한 샘플입니다.
아래 빈칸을 채우는 작은 변경을 브랜치에서 만들고 → 커밋 → push → PR → 머지해 보세요.

## 실습 과제
아래 "오늘 배운 것"에 한 줄을 채워 넣는 것이 이번 PR의 변경 내용입니다.

### 오늘 배운 것
- (여기에 한 줄 적기)

## 연습 순서 (치트시트)
```bash
git switch -c practice/fill-note      # 1) 브랜치 생성
# docs/연습-노트.md 의 "오늘 배운 것"에 한 줄 추가
git add docs/연습-노트.md             # 2) 스테이징
git commit -m "docs: 연습 노트에 오늘 배운 것 기록"   # 3) 커밋
git push -u origin practice/fill-note # 4) push
gh pr create --fill                   # 5) PR 생성 (또는 웹에서)
gh pr diff                            # 6) diff 확인 (셀프 리뷰)
gh pr merge --merge --delete-branch   # 7) 머지 + 브랜치 정리
git switch main && git pull           # 8) 로컬 main 동기화
```

## 체크리스트
- [ ] 브랜치에서 작업했는가 (main에서 직접 X)
- [ ] 커밋 메시지가 변경 내용을 설명하는가
- [ ] PR diff에 의도한 변경만 담겼는가
- [ ] 머지 후 브랜치를 삭제했는가
